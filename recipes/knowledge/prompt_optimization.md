# 提示词优化知识库（AI 助手专用）

> 本文件是「AI 优化描述 / 视觉校验」功能的**知识库**：AI 助手在优化用户输入时，
> 把这里的内容作为系统知识注入。技术美术可以直接编辑本文件调整优化口径，
> 无需改代码（改动即时生效，AI 每次调用都会读到最新版）。

## 一、3D 生成提示词的最佳实践（image-to-3D / text-to-3D 通用）

1. **单一主体原则**：一次生成一个物体。描述里出现"剑和盾"会得到缝合怪；
   应拆成两次生成。组合物（如"带底座的奖杯"）可以，但必须是物理相连的一体物。
2. **完整可见**：描述的物体不能有"藏在里面看不见的部分"（如"敞开的抽屉内部
   塞满金币"——生成模型看不见内部，会 hallucinate）。优先描述闭合外轮廓。
3. **材质与风格要具体**："好看" "精致" 是无效词。有效词是：stylized（风格化）、
   realistic（写实）、hand-painted（手绘贴图）、PBR、low-poly、voxel、
   cartoon、dark fantasy、cel-shading 等。
4. **用途语境**：说明这是 game asset / game prop，让模型倾向干净拓扑与
   中性姿态，而不是雕塑感构图。
5. **比例锚点**：给一个参照物（"约 30cm 高的桌面摆件" "一人高的门"），
   能显著改善比例合理性。
6. **避免**：文字/水印/logo（生成必然乱码）、极端细长或超薄结构（脆断）、
   透明/发光材质表述（3D 生成不支持）、多人/多角色场景。
7. **概念图建议**（有图时）：中性纯色背景、物体完整入镜、单一光源、
   正面或 3/4 视角；多视图（正/侧/背）能明显提升还原度。

## 二、本项目校验口径（优化提示词时要对齐，否则生成后过不了校验）

- 面数预算：默认 ≤ 5000 三角面（标准道具），描述里避免"极其精细的雕刻细节"，
  那类细节减面后必然糊掉；需要细节用贴图表现而非几何。
- 轴心：底面中心、落地摆放 —— 避免"悬浮的" "飞在空中的"物体描述。
- 尺寸：规格里写了期望尺寸（expected_size_m），描述里的比例锚点应与其一致。
- 命名：资产名需匹配 ^SM_[A-Za-z0-9_]+$（描述不含命名，命名在资产名输入框）。

## 三、类目词汇表（按规格预设的 category 选用）

- **prop（道具）**：weapon / tool / container / furniture / treasure / lantern / barrel / crate
- **blocker（灰盒）**：简单体块优先，描述到"形状与比例"即可，无需材质词
- **foliage（植被）**：tree / stump / bush / rock cluster；允许三角形、叠叶结构

## 四、输出要求

优化结果必须是**一段可直接使用的中文描述**（生成模型对中文支持良好），
附带 3-8 个英文关键词（多数 3D 生成模型对英文风格词更敏感）。
不要输出任何与生成无关的内容（使用说明、免责、客套）。
