# samples

冒烟测试与手工验证用的样例资产。

## 这里有什么

目前**没有预置二进制样例**（3D 文件体积大，且容易过期）。
样例由测试代码在运行时生成 —— 这样样例的形态永远和当前代码一致，不会出现
"样例是半年前的，跑不通了但没人知道为什么"。

- `services/agent/tests/conftest.py` 里的 `dirty_glb` 夹具：一个刻意"脏"的网格
  （高面数 + 游离组件 + 退化面 + 无 UV），模拟云端生成模型的典型状态。
- `services/agent/app/smoke.py`：端到端冒烟测试，会自己造一张假概念图，
  走完"概念图 → 生成 → 管线 → 校验 → 导出"全流程。

## 手工验证

想拿真实文件手工试，把网格丢这里即可（`.gitignore` 对 `samples/` 下的
`*.obj` / `*.glb` / `*.ply` 做了例外，但除非确实要长期保留，不建议提交）：

```bash
cd services/agent
python -m app.smoke --keep --dir ../../.data/smoke
```

产物会留在 `.data/smoke`，可以直接用桌面端打开这个数据目录查看。

## 黄金概念图集（W0 待补）

按开发计划，W0 需要冻结 **10 张黄金概念图**作为全程回归基线（见 `docs/ROADMAP.md`）。
这批图应该放在 `samples/golden/`，并且**冻结之后不再更换** —— 否则每次验收
都在换考卷，进度无从判断。

选取标准建议：
- 覆盖 3 个类目：硬表面道具、大型陈设、关卡灰盒
- 包含 2–3 张难度较高的（复杂镂空、多部件、细长结构）
- 分辨率与实际工作流一致（美术真实在用的概念图，而不是精挑的展示图）
